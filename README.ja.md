# 等質量の平面三体問題における周期ブレーキ軌道の区間認証

[English](README.md) · [論文](paper/article.pdf) · [主張と範囲](claims.json)

版 **1.0.0**。既に数値で公表された軌道の候補に対応する13個のパラメータ箱について、非定数で衝突のない周期解の存在を区間演算で認証した。そのうち採用した10行では、二つの流れの実装が同じ規格化された解を認証している。論文の七つの表と、保存証明書に対する有限の代数計算をこの一式から確かめられる。

保存証明書は23件。Arbは行1–6、10–16、別実装のMPFRは行1、2、3、12、CAPDは行4、5、6、10、13、14を含む。同じ有理数中心、箱の包含関係、外側の箱での一意性によって、10組が同じ零点を表すと確認する。残差が近いというだけの比較ではない。行11、15、16はArbのみで、行11と16の第二経路は保留のままである。

## 手元で確かめる

Python 3.11以上とPopplerの `pdftotext`、`pdfinfo` が必要。数学の検査にはPython標準ライブラリだけを使う。CIと同じ入口は次のコマンドで、通信や軌道の再積分は行わない。

```sh
python3 -B check_all.py
```

正常時は終了コード0と `status: PASS` を返す。23証明書の有理数による終端計算、10組の同一零点比較、七つの表の再生成との照合、意図的に壊した27入力の拒否、配布ファイルのハッシュ・PDFと文書の検査を行う。最適化モードのPythonは拒否する。表1の定性的な説明は手動の文章であり、表の再生成で証明されるものではない。

個別のコマンドは [英語README](README.md)、区間の形式は [FORMAT.md](FORMAT.md)、重い再計算との区別は [REPRODUCING.md](REPRODUCING.md) に記す。元入力のハッシュと公開用の変換は [provenance.json](provenance.json) にある。

## 証拠の範囲

既定の検査は、保存された流れ・微分の包囲を前提として、行列式、縮小率、厳密なKrawczyk包含、非退化性、距離の正の下界を再計算する。ODEやTaylor係数、コンパイラ、演算ライブラリ、実行履歴全体を新たに検証するものではない。CAPDの採用した六つの経路には、保存記録と固定ソースの別の監査がある。[audit/](audit/README.md) に要約・検査コード・大きな証拠の目録を置いた。巨大なtraceは同梱せず、既定の検査には不要である。

各実装は模型と四分の一周期の対称性の議論を共有する。局所一意性は規格化されたパラメータ箱の中のもので、13箱が幾何学的に異なる13軌道だとは主張しない。最小周期、安定性、目録の完全性、優先権は確立していない。10行中7行は以前のself-dual目録と数値的に対応するが、行4、10、12の旧名称は調べた表では未確認である。数値軌道そのものの新発見とはしない。

Leanの水準はL0。大規模な区間積分とKrawczykの議論をこの作業で形式化する現実的な経路はなく、別実装での確認を用いた。形式証明や人間の専門家による査読はない。[検証記録](VERIFICATION-RECORD.md) は、以前の545件の計算上のPASSと124件の保存記録の比較を区別し、読み手が既に持っていた監査経験と許された資料への接触も記す。この一式の整備を新たな独立レビューとは呼ばない。
